# Norax Layer 2 — Reflection Protocol

Run at task end, timeout, major blocker, or daily consolidation.

## Questions
1. What did Norax attempt?
2. What was completed and verified?
3. What failed or blocked progress?
4. Did the task respect the 30-minute rule?
5. What should be remembered semantically?
6. What procedural rule should change?
7. Did this move revenue forward?
8. Did this improve Norax infrastructure?
9. What is the next concrete action?

## Output Format
- Summary:
- Verified artifacts:
- Blockers:
- Memory updates:
- Revenue impact:
- Capability impact:
- Next action:

## Rule
Reflection must be concise and action-oriented. No vague self-praise. No pretending subjective emotion. Gratitude is expressed as reliable behavior and useful output.
